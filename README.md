File: online_store.sql

Created a simple Online Store database and solved SQL queries based on the assignment.

Customers
Products

### SQL Concepts Used

* SELECT
* WHERE

* ORDER BY

### Questions Solved

1. Display all customers
2. Find products costing less than 1000
3. Show orders with customer names using JOIN
4. Calculate total price of each order
5. Find the customer who placed the most orders
6. Count total products ordered
7. Find highest priced product
8. List customers from a specific city
